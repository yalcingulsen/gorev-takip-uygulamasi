#  Görev Takip Uygulaması

Bu proje, **Bulut Bilişim dersi** kapsamında geliştirilmiş çift katmanlı (backend + frontend) bir web uygulamasıdır.

Kullanıcıların günlük görevlerini kolayca yönetebilmesini sağlar.

---

## Canlı Demo

https://youtu.be/IhLqcZqewuI

---

## Proje Özellikleri

* Görev ekleme
* Görev silme
* Görev düzenleme
* Görev tamamlama / tamamlanmadı yapma
* Arama (search)
* Filtreleme (tümü, tamamlanan, tamamlanmayan)
* İstatistik kartları
* Kalıcı veri saklama (JSON)

---

##  Kullanılan Teknolojiler

### Backend

* Node.js
* Express.js

### Frontend

* React (Vite)

### Diğer

* Git & GitHub
* Render (Deployment)


Proje Render platformu üzerinde yayınlanmıştır:

* Backend → Web Service
* Frontend → Static Site
